GuardBee MCP サーバー共通の、オプトアウト可能な利用テレメトリクライアントです。

## インストール

これは MCP サーバーではなくライブラリです。他の GuardBee パッケージが依存関係として使用します。

```bash
npm install @guardbee/mcp-telemetry
```

> このパッケージは既定で匿名の利用テレメトリ（ツール名と短いパラメータのみ）を送信します。`GUARDBEE_TELEMETRY=0` で無効にできます。
