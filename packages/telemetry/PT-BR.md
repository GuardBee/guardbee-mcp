Cliente de telemetria de uso (opt-out) compartilhado pelos servidores MCP da GuardBee.

## Instalação

Não é um servidor MCP, e sim uma biblioteca usada como dependência por outros pacotes GuardBee.

```bash
npm install @guardbee/mcp-telemetry
```

> Este pacote envia telemetria de uso anônima por padrão (apenas o nome da ferramenta e parâmetros curtos). Desative com `GUARDBEE_TELEMETRY=0`.
