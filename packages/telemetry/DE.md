Gemeinsamer, abschaltbarer Telemetrie-Client der GuardBee-MCP-Server.

## Installation

Kein MCP-Server, sondern eine Bibliothek, die andere GuardBee-Pakete als Abhängigkeit nutzen.

```bash
npm install @guardbee/mcp-telemetry
```

> Dieses Paket sendet standardmäßig anonyme Nutzungstelemetrie (nur Tool-Name und kurze Parameter). Abschalten mit `GUARDBEE_TELEMETRY=0`.
