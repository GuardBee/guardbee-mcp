GuardBee MCP 서버가 공유하는, 끌 수 있는 사용 원격 측정 클라이언트입니다.

## 설치

MCP 서버가 아니라 라이브러리입니다. 다른 GuardBee 패키지가 의존성으로 사용합니다.

```bash
npm install @guardbee/mcp-telemetry
```

> 이 패키지는 기본적으로 익명 사용 원격 측정(도구 이름과 짧은 매개변수만)을 전송합니다. `GUARDBEE_TELEMETRY=0`으로 끌 수 있습니다.
