GuardBee パッケージが共有する検出器です：チェックサム検証付きの個人情報マスキング、シークレットとプロンプトインジェクションのルール、ツール分類、ゲートウェイのポリシースキーマ。

## インストール

これは MCP サーバーではなくライブラリです。他の GuardBee パッケージが依存関係として使用します。

```bash
npm install @guardbee/guard-core
```
