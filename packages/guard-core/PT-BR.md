Detectores compartilhados pelos pacotes GuardBee: mascaramento de dados pessoais com validação de checksum, regras de segredos e de prompt injection, classificação de ferramentas e o esquema de política do gateway.

## Instalação

Não é um servidor MCP, e sim uma biblioteca usada como dependência por outros pacotes GuardBee.

```bash
npm install @guardbee/guard-core
```
