Gemeinsame Detektoren der GuardBee-Pakete: prüfsummenvalidierte Maskierung personenbezogener Daten, Secret- und Prompt-Injection-Regeln, Tool-Klassifizierung und das Policy-Schema des Gateways.

## Installation

Kein MCP-Server, sondern eine Bibliothek, die andere GuardBee-Pakete als Abhängigkeit nutzen.

```bash
npm install @guardbee/guard-core
```
