Detectores compartidos por los paquetes de GuardBee: enmascaramiento de datos personales con validación de checksum, reglas de secretos y de prompt injection, clasificación de herramientas y el esquema de política del gateway.

## Instalación

No es un servidor MCP, sino una biblioteca que otros paquetes de GuardBee usan como dependencia.

```bash
npm install @guardbee/guard-core
```
