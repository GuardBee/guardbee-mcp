GuardBee 패키지가 공유하는 탐지기입니다: 체크섬 검증 개인정보 마스킹, 시크릿·프롬프트 인젝션 규칙, 도구 분류, 게이트웨이 정책 스키마.

## 설치

MCP 서버가 아니라 라이브러리입니다. 다른 GuardBee 패키지가 의존성으로 사용합니다.

```bash
npm install @guardbee/guard-core
```
