MCP セキュリティゲートウェイです。複数の MCP サーバーをひとつのポリシーの背後に置き、有害なデータフロー（lethal trifecta）の遮断、承認、個人情報のマスキング、OIDC ユーザー、クォータ、OpenTelemetry、ハッシュチェーン監査ログを提供します。

## インストール

```bash
npx -y @guardbee/mcp-security-proxy@^1 init --client claude-desktop
```

> このパッケージは既定で匿名の利用テレメトリ（ツール名と短いパラメータのみ）を送信します。`GUARDBEE_TELEMETRY=0` で無効にできます。
