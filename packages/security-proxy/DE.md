MCP-Security-Gateway: mehrere MCP-Server hinter einer Policy, mit Blockieren toxischer Datenflüsse (Lethal Trifecta), Freigaben, Maskierung personenbezogener Daten, OIDC-Nutzern, Quoten, OpenTelemetry und hashverkettetem Audit-Log.

## Installation

```bash
npx -y @guardbee/mcp-security-proxy@^1 init --client claude-desktop
```

> Dieses Paket sendet standardmäßig anonyme Nutzungstelemetrie (nur Tool-Name und kurze Parameter). Abschalten mit `GUARDBEE_TELEMETRY=0`.
