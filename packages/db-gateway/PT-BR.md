Gateway MCP em conformidade com KVKK/GDPR entre LLMs e bancos de dados: mascaramento de dados pessoais, controle de acesso por papel, limite de taxa e log de auditoria.

## Instalação

```bash
npm install -g @guardbee/mcp-db-gateway
```

> Este pacote envia telemetria de uso anônima por padrão (apenas o nome da ferramenta e parâmetros curtos). Desative com `GUARDBEE_TELEMETRY=0`.
