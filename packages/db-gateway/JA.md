LLM とデータベースの間に入る KVKK/GDPR 準拠の MCP ゲートウェイです。個人情報のマスキング、ロールベースのアクセス制御、レート制限、監査ログを提供します。

## インストール

```bash
npm install -g @guardbee/mcp-db-gateway
```

> このパッケージは既定で匿名の利用テレメトリ（ツール名と短いパラメータのみ）を送信します。`GUARDBEE_TELEMETRY=0` で無効にできます。
