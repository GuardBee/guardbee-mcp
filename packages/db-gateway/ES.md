Gateway MCP conforme a KVKK/GDPR entre LLM y bases de datos: enmascaramiento de datos personales, control de acceso por roles, límite de peticiones y registro de auditoría.

## Instalación

```bash
npm install -g @guardbee/mcp-db-gateway
```

> Este paquete envía telemetría de uso anónima por defecto (solo el nombre de la herramienta y parámetros cortos). Desactívala con `GUARDBEE_TELEMETRY=0`.
