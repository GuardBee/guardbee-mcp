KVKK/DSGVO-konformes MCP-Gateway zwischen LLMs und Datenbanken: Maskierung personenbezogener Daten, rollenbasierte Zugriffskontrolle, Rate Limiting und Audit-Log.

## Installation

```bash
npm install -g @guardbee/mcp-db-gateway
```

> Dieses Paket sendet standardmäßig anonyme Nutzungstelemetrie (nur Tool-Name und kurze Parameter). Abschalten mit `GUARDBEE_TELEMETRY=0`.
