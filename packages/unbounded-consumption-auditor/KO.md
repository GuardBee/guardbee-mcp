LLM/에이전트 코드에서 OWASP LLM Top 10 2026의 6위 '무제한 소비(denial of wallet)' 패턴을 찾습니다: 출력 토큰 제한 누락, 직접 만든 LLM HTTP 호출의 타임아웃 누락, 무제한 도구 호출·재시도 루프, 비활성화된 안전 한도, 속도 제한 없는 MCP 도구.

## 설치

```bash
npx -y @guardbee/mcp-unbounded-consumption-auditor
```

Claude Desktop:

```json
{
  "mcpServers": {
    "unbounded-consumption-auditor": {
      "command": "npx",
      "args": [
        "-y",
        "@guardbee/mcp-unbounded-consumption-auditor"
      ]
    }
  }
}
```

## MCP 도구

`scan_text`, `scan_file`, `scan_directory`, `list_patterns`

각 도구의 자세한 설명은 [README.md](README.md)에 있습니다.

npx @guardbee/mcp-unbounded-consumption-auditor --help
