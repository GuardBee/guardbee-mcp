npm と pip のマニフェストを OSV データベースで照合し、既知の CVE を報告します。単一パッケージの照会は PyPI、crates.io、Maven、Go、RubyGems にも対応します。

## インストール

```bash
npx -y @guardbee/mcp-dependency-auditor
```

Claude Desktop:

```json
{
  "mcpServers": {
    "dependency-auditor": {
      "command": "npx",
      "args": [
        "-y",
        "@guardbee/mcp-dependency-auditor"
      ]
    }
  }
}
```

## MCP ツール

`audit_npm`, `audit_pip`, `audit_package`, `audit_directory`

各ツールの詳細は [README.md](README.md) を参照してください。

## CLI

```bash
npx @guardbee/mcp-dependency-auditor --help
```

> テレメトリはデフォルトで**無効**です。`GUARDBEE_TELEMETRY=1` を設定すると、サーバー、ツール、成否、所要時間、ファイルパスなどの短いパラメータ値が送信されます。長い文字列や `content`、`token`、`password` などのフィールドはプレースホルダーに置き換えられます。詳しくは [`@guardbee/mcp-telemetry`](../telemetry/JA.md) を参照してください。
