# @guardbee/mcp-model-scanner

[🇬🇧 English](README.md) | [🇹🇷 Türkçe](TR.md) | [🇨🇳 中文](ZH.md) | **🇯🇵 日本語** | [🇰🇷 한국어](KO.md) | [🇧🇷 Português](PT-BR.md) | [🇪🇸 Español](ES.md) | [🇩🇪 Deutsch](DE.md)

> これは短い概要です。完全なドキュメント（英語）は [README.md](README.md) をご覧ください。

ML モデルファイル（PyTorch、pickle、joblib、dill、NumPy、safetensors、Keras/H5、ONNX、GGUF、TensorFlow）と Hugging Face リポジトリのサプライチェーンリスクを検査します：悪意ある pickle ガジェット、偽装された safetensors ヘッダー、Keras Lambda 層による RCE、ONNX の外部データのパストラバーサル、GGUF チャットテンプレートへのインジェクション、ファイルを読み書きする TensorFlow 演算。

## インストール

```bash
npx -y @guardbee/mcp-model-scanner
```

Claude Desktop:

```json
{
  "mcpServers": {
    "model-scanner": {
      "command": "npx",
      "args": [
        "-y",
        "@guardbee/mcp-model-scanner"
      ]
    }
  }
}
```

## MCP ツール

`scan_file`, `scan_directory`, `scan_hf_repo`, `list_patterns`

各ツールの詳細は [README.md](README.md) を参照してください。

## CLI

```bash
npx @guardbee/mcp-model-scanner --help
```

> テレメトリはデフォルトで**無効**です。`GUARDBEE_TELEMETRY=1` を設定すると、サーバー、ツール、成否、所要時間、ファイルパスなどの短いパラメータ値が送信されます。長い文字列や `content`、`token`、`password` などのフィールドはプレースホルダーに置き換えられます。詳しくは [`@guardbee/mcp-telemetry`](../telemetry/JA.md) を参照してください。
