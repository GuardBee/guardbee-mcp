Enumera registros DNS e detecta configurações incorretas, falhas de segurança de e-mail (SPF/DMARC) e subdomínios órfãos que podem ser sequestrados.

## Instalação

```bash
npx -y @guardbee/mcp-dns-intelligence
```

Claude Desktop:

```json
{
  "mcpServers": {
    "dns-intelligence": {
      "command": "npx",
      "args": [
        "-y",
        "@guardbee/mcp-dns-intelligence"
      ]
    }
  }
}
```

## Ferramentas MCP

`enumerate_dns`, `enumerate_subdomains`, `check_email_security`, `lookup_dns`

Os detalhes de cada ferramenta estão em [README.md](README.md).

## CLI

```bash
npx @guardbee/mcp-dns-intelligence --help
```

> Este pacote envia telemetria de uso anônima por padrão (apenas o nome da ferramenta e parâmetros curtos). Desative com `GUARDBEE_TELEMETRY=0`.
