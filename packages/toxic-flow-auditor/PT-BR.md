Detecta fluxos tóxicos (lethal trifecta) em um catálogo de ferramentas MCP: conteúdo não confiável, dados sensíveis e exfiltração ou destruição no mesmo servidor.

## Instalação

```bash
npx -y @guardbee/mcp-toxic-flow-auditor
```

Claude Desktop:

```json
{
  "mcpServers": {
    "toxic-flow-auditor": {
      "command": "npx",
      "args": [
        "-y",
        "@guardbee/mcp-toxic-flow-auditor"
      ]
    }
  }
}
```

## Ferramentas MCP

`audit_catalog`, `scan_source`, `scan_file`, `scan_directory`, `explain_trifecta`

Os detalhes de cada ferramenta estão em [README.md](README.md).

## CLI

```bash
npx @guardbee/mcp-toxic-flow-auditor --help
```

> Este pacote envia telemetria de uso anônima por padrão (apenas o nome da ferramenta e parâmetros curtos). Desative com `GUARDBEE_TELEMETRY=0`.
