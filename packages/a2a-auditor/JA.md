Agent2Agent (A2A) プロトコルの実装コードを走査し、認証のないプッシュ通知 Webhook（SSRF）、認証要件のない Agent Card、公開される Agent Card に埋め込まれた認証情報を検出します。

## インストール

```bash
npx -y @guardbee/mcp-a2a-auditor
```

Claude Desktop:

```json
{
  "mcpServers": {
    "a2a-auditor": {
      "command": "npx",
      "args": [
        "-y",
        "@guardbee/mcp-a2a-auditor"
      ]
    }
  }
}
```

## MCP ツール

`scan_text`, `scan_file`, `scan_directory`, `list_patterns`

各ツールの詳細は [README.md](README.md) を参照してください。

## CLI

```bash
npx @guardbee/mcp-a2a-auditor --help
```

> このパッケージは既定で匿名の利用テレメトリ（ツール名と短いパラメータのみ）を送信します。`GUARDBEE_TELEMETRY=0` で無効にできます。
