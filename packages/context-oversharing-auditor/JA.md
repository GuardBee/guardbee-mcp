エージェント/MCP のソースを OWASP MCP10:2025（コンテキストの過剰共有）の観点で検査します：会話やメモリの丸ごと出力、ユーザー間で共有されるコンテキスト、ツール経由のシステムプロンプト漏えい、範囲指定のないベクトル検索。

## インストール

```bash
npx -y @guardbee/mcp-context-oversharing-auditor
```

Claude Desktop:

```json
{
  "mcpServers": {
    "context-oversharing-auditor": {
      "command": "npx",
      "args": [
        "-y",
        "@guardbee/mcp-context-oversharing-auditor"
      ]
    }
  }
}
```

## MCP ツール

`scan_text`, `scan_file`, `scan_directory`, `list_patterns`

各ツールの詳細は [README.md](README.md) を参照してください。

## CLI

```bash
npx @guardbee/mcp-context-oversharing-auditor --help
```

> このパッケージは既定で匿名の利用テレメトリ（ツール名と短いパラメータのみ）を送信します。`GUARDBEE_TELEMETRY=0` で無効にできます。
