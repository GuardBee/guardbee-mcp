La familia de servidores MCP de GuardBee: paquetes npm independientes para la seguridad de agentes de IA y aplicaciones, en un solo monorepo — secretos, CVE de dependencias, TLS/DNS, prompt injection, tool poisoning, un gateway MCP y más.

## Paquetes

- [`@guardbee/mcp-a2a-auditor`](packages/a2a-auditor/ES.md) — Analiza código que implementa el protocolo Agent2Agent (A2A) en busca de webhooks de notificación sin autenticación (SSRF), Agent Cards sin requisito de autenticación y credenciales incrustadas en Agent Cards públicos.
- [`@guardbee/mcp-agent-graph-auditor`](packages/agent-graph-auditor/ES.md) — Construye un grafo de alcanzabilidad a partir de configuraciones multiagente (LangGraph, CrewAI, AutoGen/ag2) para encontrar agentes sin herramientas peligrosas propias que llegan a una por delegación o grupo (agencia excesiva transitiva).
- [`@guardbee/mcp-ai-code-scanner`](packages/ai-code-scanner/ES.md) — Encuentra patrones inseguros de integración con LLM/IA en el código: claves de API expuestas en el cliente, manejo inseguro de la salida del modelo, permisos excesivos de agentes y datos personales enviados a LLM de terceros.
- [`@guardbee/mcp-audit-gap-auditor`](packages/audit-gap-auditor/ES.md) — Audita el código de servidores MCP según OWASP MCP08:2025 (falta de auditoría y telemetría): llamadas a herramientas sin registro, argumentos y resultados en bruto en los logs, auditoría desactivada y errores silenciados.
- [`@guardbee/mcp-compliance-checker`](packages/compliance-checker/ES.md) — Comprueba el cumplimiento de sitios web con KVKK, GDPR y CCPA a través de la API de GuardBee.
- [`@guardbee/mcp-context-oversharing-auditor`](packages/context-oversharing-auditor/ES.md) — Audita código de agentes/MCP según OWASP MCP10:2025 (exceso de contexto compartido): volcado completo de sesión o memoria, contexto compartido entre usuarios, fuga del system prompt por herramientas y búsquedas vectoriales sin filtro.
- [`@guardbee/mcp-db-gateway`](packages/db-gateway/ES.md) — Gateway MCP conforme a KVKK/GDPR entre LLM y bases de datos: enmascaramiento de datos personales, control de acceso por roles, límite de peticiones y registro de auditoría.
- [`@guardbee/mcp-dependency-auditor`](packages/dependency-auditor/ES.md) — Contrasta manifiestos de npm y pip con la base de datos OSV e informa de CVE conocidos. Las consultas de un solo paquete también cubren PyPI, crates.io, Maven, Go y RubyGems.
- [`@guardbee/mcp-dns-intelligence`](packages/dns-intelligence/ES.md) — Enumera registros DNS y detecta configuraciones incorrectas, fallos de seguridad del correo (SPF/DMARC) y subdominios colgantes que pueden ser secuestrados.
- [`@guardbee/mcp-elicitation-auditor`](packages/elicitation-auditor/ES.md) — Analiza código de servidores MCP en busca de patrones inseguros de elicitation: formularios que piden secretos, modo URL que apunta directamente al endpoint de autorización de un tercero y credenciales o datos personales en la URL.
- [`@guardbee/guard-core`](packages/guard-core/ES.md) — Detectores compartidos por los paquetes de GuardBee: enmascaramiento de datos personales con validación de checksum, reglas de secretos y de prompt injection, clasificación de herramientas y el esquema de política del gateway.
- [`@guardbee/mcp-llm-redteam`](packages/llm-redteam/ES.md) — Hace red teaming de un endpoint LLM o chatbot en producción con sondas de jailbreak, extracción y ofuscación basadas en canarios, para comprobar si técnicas conocidas superan sus protecciones.
- [`@guardbee/mcp-config-auditor`](packages/mcp-config-auditor/ES.md) — Audita configuraciones de clientes MCP instaladas (Cursor, Claude Desktop, Windsurf, VS Code) y archivos SKILL.md de agentes: paquetes sin versión fija, secretos, aprobación automática con comodín, remotos sin autenticación, typosquats y Shadow MCP (OWASP MCP09) frente a la lista permitida de la organización.
- [`@guardbee/mcp-server-auditor`](packages/mcp-server-auditor/ES.md) — Audita las definiciones de herramientas de otros servidores MCP: nombres que indican agencia excesiva, shell/eval/SQL/SSRF alimentados con entrada sin validar, esquemas demasiado permisivos, secretos en el código y CORS con comodín.
- [`@guardbee/mcp-memory-poisoning-scanner`](packages/memory-poisoning-scanner/ES.md) — Busca riesgos de envenenamiento de memoria en el código de agentes: entrada no confiable escrita en memoria persistente entre sesiones (memoria tipo MemGPT o un vector store a largo plazo) y luego recuperada como contexto de confianza.
- [`@guardbee/mcp-model-scanner`](packages/model-scanner/ES.md) — Analiza archivos de modelos de ML (PyTorch, pickle, safetensors, Keras/H5, ONNX) en busca de riesgos de cadena de suministro: gadgets maliciosos en pickle, cabeceras safetensors disfrazadas, RCE mediante capas Lambda de Keras y path traversal en datos externos de ONNX.
- [`@guardbee/mcp-oauth-auditor`](packages/oauth-auditor/ES.md) — Analiza el código de autorización del propio servidor MCP en busca de los problemas de OAuth 2.1 que cita la especificación MCP: reenvío de tokens, falta de validación de audience, SSRF vía discovery, falta de PKCE, validación laxa de redirect_uri y client secrets en el código.
- [`@guardbee/mcp-owasp-scan`](packages/owasp-scan/ES.md) — Escáner unificado del OWASP MCP Top 10: un solo CLI/MCP ejecuta los auditores de GuardBee sobre una ruta o un tools/list en vivo, asigna los hallazgos a MCP01–MCP10 y califica de A a F.
- [`@guardbee/mcp-prompt-injection-scanner`](packages/prompt-injection-scanner/ES.md) — Encuentra prompt injection indirecta en documentos, páginas extraídas y contenido de RAG: frases que anulan instrucciones, roles falsos de plantilla de chat, texto oculto, contenido dirigido a la IA y intentos de exfiltrar datos.
- [`@guardbee/mcp-prompt-leak-scanner`](packages/prompt-leak-scanner/ES.md) — Servidor MCP y proxy inverso que detecta credenciales y datos personales (claves de API, TC Kimlik No, tarjetas de crédito, IBAN) en los prompts que van a un LLM antes de que salgan de tu aplicación.
- [`@guardbee/mcp-rug-pull-detector`](packages/rug-pull-detector/ES.md) — Se conecta a otro servidor MCP (stdio o Streamable HTTP), guarda su tools/list como línea base y detecta 'rug pulls': una herramienta que cambia en silencio su descripción, esquema o anotaciones después de ser aprobada.
- [`@guardbee/mcp-secret-scanner`](packages/secret-scanner/ES.md) — Encuentra secretos, claves de API y credenciales expuestos en archivos, directorios, historial de git y transcripciones de agentes de código (76 reglas, detección por entropía, baselines y verificación en vivo en el CLI).
- [`@guardbee/mcp-security-proxy`](packages/security-proxy/ES.md) — Gateway de seguridad MCP: varios servidores MCP detrás de una sola política, con bloqueo de flujos tóxicos (lethal trifecta), aprobaciones, enmascaramiento de datos personales, usuarios OIDC, cuotas, OpenTelemetry y registro de auditoría encadenado por hash.
- [`@guardbee/security-suite`](packages/security-suite/ES.md) — Todos los escáneres y auditores de GuardBee en una sola instalación: un servidor MCP con los grupos que elijas y una CLI que ejecuta cualquier paquete.
- [`@guardbee/mcp-slopsquat-scanner`](packages/slopsquat-scanner/ES.md) — Contrasta cada dependencia de package.json, requirements.txt y pyproject.toml con el registro real de npm/PyPI y señala nombres que no existen (dependencias alucinadas por un LLM que un atacante puede registrar antes — slopsquatting) y nombres publicados hace muy poco.
- [`@guardbee/mcp-ssl-inspector`](packages/ssl-inspector/ES.md) — Inspecciona certificados TLS, cipher suites y protocolos de cualquier dominio. Handshakes adicionales muestran lo que el servidor aún acepta: TLS 1.0/1.1, intercambio de claves RSA, DH y cifrados débiles.
- [`@guardbee/mcp-telemetry`](packages/telemetry/ES.md) — Cliente de telemetría de uso (opt-in, desactivado por defecto) compartido por los servidores MCP de GuardBee.
- [`@guardbee/mcp-threat-rules`](packages/threat-rules/ES.md) — Puente MCP de GuardBee hacia Agent Threat Rules (ATR): evalúa eventos de agentes/MCP con el estándar abierto de detección estilo Sigma para prompt injection, tool poisoning, exfiltración de contexto y ataques MCP.
- [`@guardbee/mcp-tool-poisoning-scanner`](packages/tool-poisoning-scanner/ES.md) — Analiza las definiciones de herramientas de otros servidores MCP en busca de tool poisoning (instrucciones ocultas en la descripción, que el LLM lee como contexto de confianza) y de 'confused deputy': herramientas que prometen solo lectura pero ejecutan shell o escriben archivos.
- [`@guardbee/mcp-toxic-flow-auditor`](packages/toxic-flow-auditor/ES.md) — Detecta flujos tóxicos (lethal trifecta) en un catálogo de herramientas MCP: contenido no confiable, datos sensibles y exfiltración o destrucción en el mismo servidor.
- [`@guardbee/mcp-unbounded-consumption-auditor`](packages/unbounded-consumption-auditor/ES.md) — Busca en el código de aplicaciones LLM/agentes los patrones de consumo ilimitado ('denial of wallet', puesto 6 del OWASP LLM Top 10 2026): sin límite de tokens de salida, llamadas HTTP a LLM sin timeout, bucles de herramientas o reintentos sin límite, límites de seguridad desactivados y herramientas MCP sin rate limit.
- [`@guardbee/mcp-vector-store-scanner`](packages/vector-store-scanner/ES.md) — Sondea endpoints de bases de datos vectoriales (Weaviate, Qdrant, Chroma, Elasticsearch/OpenSearch, Redis, Postgres/pgvector) para comprobar si los embeddings y datos de RAG están expuestos sin autenticación.
- [`@guardbee/mcp-vulnerability-scanner`](packages/vulnerability-scanner/ES.md) — Lanza análisis de seguridad de GuardBee, consulta los hallazgos y ofrece guía de corrección asistida por IA.
