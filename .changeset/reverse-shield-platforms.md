iOS (`.ipa` and `.app`: Debug-configuration builds, development profiles, React Native and web code), Android App Bundles (`.aab`), and engine checks for Unity (IL2CPP metadata, Mono assemblies), PyInstaller, Java/Spring Boot JARs and Flutter. New `suggest_fixes` tool / `suggest` command turns findings into build-config diffs (Vite, webpack, Next.js, Angular, CRA, Gradle, Android manifest, React Native, electron-builder, .NET). Baselines (`--baseline`, `--update-baseline`, SARIF `baselineState`), `ignore` rules in guardbee.yml, and a GitHub Action at `.github/actions/reverse-shield`.
