# Changesets

Her PR'a değişiklik açıklayan bir changeset ekleyin:

```
pnpm changeset
```

Sadece dokunduğunuz paketleri seçin — bağımsız versiyonlanırlar. `main`'e merge olunca release workflow otomatik olarak sürüm PR'ı açar ve merge edildiğinde npm'e publish eder.

Detaylar: https://github.com/changesets/changesets
